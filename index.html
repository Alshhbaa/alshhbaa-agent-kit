Agent Setup & Protocol Endpoints

Installation commands and configuration snippets to register the skill or connect the MCP server.

أوامر التثبيت وواجهات البروتوكول

أوامر وإعدادات مباشرة لتثبيت المهارة أو ربط خادم MCP مع وكيل الذكاء الاصطناعي.

1. Install Agent Skill 1. تثبيت مهارة الوكيل

Adds catalog search, shipping estimation, and cart verification to your agent environment: تثبيت مهارة البحث في الكتالوج، وحساب تكاليف الشحن، وفحص السلة:

npx skills add alshhbaa/alshhbaa-agent-kit
2. Connect MCP Server 2. ربط خادم MCP

Add the streamable HTTP MCP server via CLI: إضافة خادم MCP المباشر عبر سطر الأوامر:

claude mcp add alshhbaa-store https://shop.alshhbaa.com/.well-known/mcp

Or add to your client MCP configuration: أو أضف الإعداد في ملف تكوين خوادم MCP: 

{
  "mcpServers": {
    "alshhbaa-store": {
      "type": "streamable-http",
      "url": "https://shop.alshhbaa.com/.well-known/mcp"
    }
  }
}

Direct Streamable HTTP endpoint: الرابط المباشر لخادم MCP (Streamable HTTP):

https://shop.alshhbaa.com/.well-known/mcp
